A focused model or API usually lands in two to three weeks. A full application with an ML component runs closer to six to eight. I scope it properly after the first call rather than guessing, and I share progress in weekly increments you can actually run.

Remote by default and comfortable joining an existing codebase, repo conventions and review process. I write code meant to be read by other people — typed, tested and documented — so onboarding your team onto it is part of the delivery, not an afterthought.
